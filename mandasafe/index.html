Paano basahin ang mapa? How to read the map
  • Mga barangay. Bawat may kulay na bahagi ay isang barangay ng Mandaluyong. Ang madilim na area sa labas ay hindi na sakop ng lungsod. I-click ang barangay para makita kung ilang aksidente ang naitala doon.
  • Pulang pin = isang aksidente. Kapag mas malaki ang pin, mas malala ang aksidente (Fatal > Injury > Minor). I-click ang pin para makita ang petsa, oras, uri ng aksidente at kalsada.
  • Barangay filter. Pumili ng barangay para i-zoom ang mapa doon at makita lang ang mga aksidente sa lugar na iyon.
  • From – To. Piliin ang petsa para makita lang ang mga aksidente sa panahong iyon — halimbawa, ngayong buwan o noong nakaraang taon. Pindutin ang Clear filters para bumalik sa lahat.
  • Zoom in / out. Pindutin ang + para lumapit at makita ang mga kalsada, at − para lumayo at makita ang buong lungsod. Puwede ring i-drag ang mapa para ilipat, o mag-pinch sa cellphone.
  • Accident Markers. I-on o i-off ang mga pin para mas malinaw na makita ang mga barangay boundary.
  • Full screen. Palakihin ang mapa sa buong screen; dito puwede ring mag-zoom gamit ang mouse wheel. Pindutin ang Esc o Exit full screen para bumalik.

Ang mga numero ay galing sa mga aksidenteng naitala sa MandaSafe, kaya nagbabago ang mapa kapag may bagong datos. Gamitin ito para malaman kung saan mas madalas ang aksidente at mag-ingat sa mga lugar na iyon.

How MandaSafe Works

Officers Record

TPMO officers log every road accident in the RIMAS admin console — date, barangay, road, type and severity.

Mapped by Barangay

Each record is placed inside the city's official barangay boundaries, by coordinates or barangay centroid.

Hotspots Found

Gaussian kernel density estimation finds true density peaks instead of a simple street count.

Next Month Forecast

A linear trend per area, adjusted by a Random Forest severity model, projects the month ahead.

Residents Informed

Everything the office records is published here so residents can plan safer routes.
